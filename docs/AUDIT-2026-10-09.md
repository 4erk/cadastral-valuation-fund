# Аудит библиотеки кадастровой оценки (09.10.2026)

## Найденные проблемы
- Старый HTML POST Росреестра больше не работает: контрольный запрос HTTP 403.
- Парсер зависел от HTML-таблицы и не проверял типы, пустые даты, число ячеек и ссылки.
- Исходный проект не содержал автоматических тестов и dev-flow.
- Старый Composer lock содержал 17 advisories в Guzzle, PSR-7, PHPUnit и Symfony YAML.
- Фонд кадастровой оценки был ошибочно связан с устаревшим источником данных.

## Исправления
- Использованы действующие JSON API НСПД: data-fund/v3 (история), v2 (график), v1 (актуальные атрибуты).
- Сохранён публичный PHP-метод searchByCadastral; отсутствие истории возвращает null, HTTP/JSON-сбои — исключение.
- История моделируется с отдельными идентификаторами, датами, исходными десятичными суммами, типами документов и ссылками на процедуры.
- Дубликаты по дате и стоимости сохранены, если записи реестра различны.
- Старый HTML Parser оставлен для совместимости и защищён от неполных строк, фиктивных дат и недостоверных ссылок.
- Зависимости обновлены, убран лишний dev-стек. Composer audit сообщает 0 известных уязвимостей.
- Добавлены unit/контрактные тесты, CI, документация, dev-flow и публикация оригинала с upstream.

## Ограничения
- Используемые endpoint'ы не гарантированы как публичный стабильный контракт.
- Проверка сертификата TLS отключена по указанию пользователя; это осознанный сетевой риск.
- Некоторые IP-маршруты до НСПД получают HTTP 403.
- Детальная карточка документа в дополнительной пробе не ответила вовремя. Основная история работает независимо.
- Эта работа НЕ выкатывает библиотеку в production GOSKADASTR; выполняется только публикация версионированного upstream.
